## 1. Edit profile (#309)
- Account tab row ar «تعديل بياناتي» / en "Edit my details" -> route /me/edit. Loads GET /me/profile, pre-fills the same onboarding steps (edit mode: a step list the user can jump into, not a forced wizard; Save button on each step), then PUT /me/profile and shows the existing result screen with the new target (or the general-mode screening message when not eligible, exactly as in onboarding).
- Health conditions limited to the three supported ones (as onboarding already does). Weight is NOT edited here (it has its own log); show a hint linking to the weight sheet.
- After a successful save: invalidate the targets/today providers so Today shows the new target; show a note ar «الخطط القادمة ستُبنى بهدفك الجديد» / en "Upcoming plans will use your new target". Existing plans are not rebuilt automatically.
- Requires a connection: offline -> disabled Save with the existing offline message.
- Tests: prefill from a fake profile, save sends the changed field, ineligible result path, offline disables save.

## 2. Appearance (#310)
- Row ar «المظهر» / en "Appearance": system / light / dark (radio sheet). Persist locally with the same mechanism the app already uses for the language choice; apply instantly via ThemeMode. Test: choice persists across a rebuild and maps to ThemeMode.

## 3. Delete account (#311)
- Row at the bottom in the danger color ar «حذف الحساب» / en "Delete account". Screen explains in plain words what is deleted (profile, plans, logs, weights, water, learning history on the server, and all data on this phone) and that it cannot be undone. The user must type ar «حذف» (or en "DELETE") to enable the button; then DELETE /me.
- On 204: run the same local wipe as logout (tokens, encrypted DB user tables, outbox, earned badges, in-memory providers) and go to /welcome with a short message. Pending outbox items are discarded (say so on the screen before confirming when the outbox is not empty).
- Offline or error: nothing is wiped; show the error, stay on the screen. 401 after refresh failure: go to login.
- Tests: button disabled until the word is typed; success wipes and navigates; failure keeps data; pending-outbox warning shown.

## 4. About and privacy (#312)
- Row ar «عن التطبيق والخصوصية» / en "About and privacy": app version (from the build), a short wellness disclaimer (this app gives general dietary guidance and does not replace a doctor or dietitian; for diabetes, high blood pressure and heart disease follow your care team), data sources (USDA FoodData Central for nutrition values), and a plain-language "How the app learns from you" paragraph: which actions it uses (eaten, swapped, rated, did not eat, saved), that it only chooses between meals that already pass every health rule, and that deleting the account deletes this learning history. No external links required.
- Test: screen renders both languages; version string present.
