## 1. Table (#306)
- `EarnedBadges`: code TEXT primary key, earned_on TEXT (YYYY-MM-DD, device local date when first detected), seen BOOL default false.
- Once earned, a badge is never removed (even if the old days later leave the local cache).

## 2. Badge rules (#307) — pure Dart in lib/features/progress/domain/badges.dart
Use exactly the same "achieved day" definition (status == 'ACHIEVED') and consecutive-date logic as the K.6a streak. Each rule returns earned (bool) and progress (current, target) for locked display:
- FIRST_LOG: >= 1 non-deleted consumption log. (1)
- FIRST_ACHIEVED_DAY: >= 1 achieved day. (1)
- STREAK_3, STREAK_7, STREAK_14, STREAK_30: longest run of consecutive achieved dates >= 3 / 7 / 14 / 30. Progress = longest run so far.
- BALANCED_WEEK: some window of 7 consecutive dates contains >= 5 achieved days. Progress = best window count / 5.
- WATER_GOAL_3: >= 3 distinct dates where the water total >= goalMl (only when a goal is set; with no goal show the hint to set one). Progress = days / 3.
- WEIGHT_TRACKER: >= 4 weight entries whose first and last dates are >= 21 days apart. Progress = entries / 4.
- EXPLORER_10: >= 10 distinct meal ids among non-deleted consumption logs. Progress = distinct / 10.
- Unit tests for every rule with edge cases: gaps break a streak, PARTIAL does not count, deleted logs ignored, null water goal, exactly-at-threshold.
