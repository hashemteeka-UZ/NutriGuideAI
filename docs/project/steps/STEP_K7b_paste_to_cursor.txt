## 1. Reminders (#313)
- Account row ar «التذكيرات» / en "Reminders": screen with three switches, all OFF by default:
  - Meal reminders: one notification at the START of each of the user's meal windows (from MealWindows / profile), text ar «حان وقت {الوجبة}. وجبتك في خطة اليوم» / en "Time for {meal}. Your meal is in today's plan".
  - Water reminders: every 2 hours between 09:00 and 21:00 local time (7 per day), ar «اشرب كوب ماء» / en "Have a glass of water". Only when a water goal is set; otherwise the switch shows the hint to set a goal.
  - Weekly weigh-in: Friday 09:00 local, ar «وقت وزنك الأسبوعي» / en "Time for your weekly weigh-in".
- Daily repeating schedules with matchDateTimeComponents (time / dayOfWeekAndTime), timezone from the existing flutter_timezone setup. Tapping a notification opens the matching tab (/today, /water, /progress).
- Android 13+: request POST_NOTIFICATIONS when the user turns the first switch on; if denied, switch returns to off with a short explanation and a button to open app settings.
- Reschedule on: switch change, profile save (meal windows may change), app start; cancel all on logout and account deletion.
- Tests: scheduling logic with a fake notifications plugin (ids, times, count = windows / 7 / 1), permission denied path, cancel on logout.
