## 2. Service `app/services/auth.py` (no FastAPI imports)
- Password hashing with `pwdlib` `PasswordHash((Argon2Hasher(),))` at its recommended defaults; one module-level hasher. `hash_password`, `verify_password`. When a stored hash needs rehash (`verify_and_update`), update it on successful login.
- Email normalisation: `strip().lower()`; the `users.email_lowercase` CHECK already enforces lower case.
- `register_user(session, email, password, now) -> TokenPair data`: insert the user; a unique violation on email raises `EmailTakenError`. Returns tokens from `issue_tokens` (new family).
- `authenticate(session, email, password, now)`: unknown email and wrong password both raise `InvalidCredentialsError`; for an unknown email still run one verification against a fixed dummy hash so the response time does not reveal whether the account exists (OWASP).
- `issue_tokens(session, user_id, now, family_id=None)`: access token = JWT HS256 with claims `sub` (user id as string), `iat`, `exp` (`now + ACCESS_TOKEN_MINUTES`), `typ: "access"`. Refresh token = `secrets.token_urlsafe(32)`; store only `sha256` hex of it in `refresh_tokens` with `family_id` (new `uuid4` unless given), `issued_at = now`, `expires_at = now + REFRESH_TOKEN_DAYS`. Return `access_token`, `refresh_token`, `expires_in` (seconds).
- `rotate_refresh(session, raw_token, now)`: look up by hash with `SELECT ... FOR UPDATE`. Not found or expired → `TokenInvalidError`. Already revoked → reuse detected (#45): revoke every non-revoked token of that family, flush, then raise `TokenReusedError`; the revocation must survive the error response, so the router commits before re-raising (document why in a comment). Otherwise revoke it (`revoked_at = now`), issue a new token in the same family, set `replaced_by_token_id`.
- `logout(session, raw_token, now)`: revoke every token of the family if the token is known; an unknown token does nothing (no error, no information leak).
- `decode_access(token, now) -> int`: verify signature and `typ`; check `exp` against the injected `now`, not the wall clock (decode with `verify_exp` off, then compare), so tests stay deterministic. Any failure raises `TokenInvalidError`.
- Exceptions: `AuthError` base; `EmailTakenError`, `InvalidCredentialsError`, `TokenInvalidError`, `TokenReusedError`. Add them to `SERVICE_ERRORS`: `EMAIL_TAKEN` 409, `INVALID_CREDENTIALS` 401, `TOKEN_INVALID` 401, `TOKEN_REUSED` 401.
