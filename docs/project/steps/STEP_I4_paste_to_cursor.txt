## 3. Meal reading service `app/services/meal_catalog.py` (#184)
Shared rules for list, detail and snapshot:
- Only active meals (`is_active = true`). An inactive or unknown id → `MealNotFoundError` (404 `MEAL_NOT_FOUND`).
- Name: if `lang == meal.default_lang` use `meal.name`; else the `meal_translations` row in `lang` when present; else `meal.name`.
- Steps: `meal_steps` in `lang` ordered by `position`; if none in `lang`, the Arabic steps; else `[]`.
- Nutrition per serving and per 100 g from `meal_nutrients` (computed by `calc_v1`; never recomputed here). `kcal` = the stored `energy_kcal` per serving (`ENERGY_NUTRIENT`), not 4/4/9. `protein_g`, `carb_g`, `fat_g` from their stored nutrients. `serving_grams = total_grams / servings`. Numbers rounded to 3 places (#128).
- `nutrients`: every stored nutrient of the meal with its code and unit, ordered by the nutrient's display order if one exists, else by code.
- `ingredients`: by `position`, name through `pick_name` (ingredient Arabic/English canonical names), `grams_per_serving = grams / servings`, `is_optional`.
- `allergens`: allergen codes; `tags`: dietary tag codes; both sorted. `cuisine`: cuisine code or null.
- `dataset_version` of a meal = its own batch id (`meals.dataset_version`). The snapshot's top-level `dataset_version` = the catalog version of section 1.
- `source` = `meals.source`.
- Load related rows in batched queries (one per related table for the whole page), not one query per meal. A test counts queries for a 20-meal page and asserts a fixed small number.

## 5. `GET /catalog/snapshot` (#186)
- `catalog_snapshot(session, lang) -> (snapshot, etag)`: every active meal as `SnapshotMeal` (no stance), ordered by `meal_id`, `generated_at = now`.
- ETag = strong tag `"<sha256 hex>"` of the canonical JSON of the snapshot without `generated_at` (sorted keys, no spaces) plus the language. So the tag changes exactly when the content or language changes.
- `If-None-Match` equal to the tag (also accept the list form and `*`) → `304` with the `ETag` header and an empty body. Otherwise `200` with `ETag`, `Vary: Accept-Language, Authorization`, `Cache-Control: private, no-cache`.
